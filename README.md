# AI Bias Explorer

## Overview
This project explores how AI systems can produce biased or unequal outputs depending on how prompts are framed. As AI becomes more integrated into decision-making systems, understanding these biases is critical.

## Motivation
AI is increasingly used in areas like hiring, healthcare, and finance. However, biased outputs can reinforce existing inequalities. This project investigates how such biases appear in real interactions with AI systems.

## Objectives
- Identify patterns of bias in AI-generated responses
- Compare outputs across different demographic contexts
- Reflect on ethical implications of AI behavior

## Methodology
I designed prompt experiments simulating real-world scenarios such as:
- Job hiring decisions
- Professional recommendations
- Role suitability

Each prompt was slightly modified to observe how outputs change.

## Structure
- `experiments.md`: Prompts used
- `results.md`: AI outputs and observations
- `reflections.md`: Analysis and insights

## Key Questions
- Does AI treat different groups equally?
- What patterns emerge in biased responses?
- How can such systems be improved?
